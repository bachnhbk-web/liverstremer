Tại sao cần Máy chủ Relay?

Trình duyệt điện thoại (Chrome/Safari) không hỗ trợ gửi trực tiếp giao thức RTMP / RTMPS. Gói livestream-relay-server.zip đi kèm sẽ nhận hình từ điện thoại qua wss:// và dùng FFmpeg đẩy song song lên cả YouTube & Facebook chuẩn H.264/AAC (khắc phục lỗi màn hình đen trên Facebook Live Producer).

Cách triển khai nhanh (Render / Railway / VPS):

  1. Giải nén tệp livestream-relay-server.zip và đẩy lên GitHub hoặc VPS.
  2. Chọn triển khai bằng Docker (đã tích hợp sẵn Node.js + FFmpeg).
  3. Lấy tên miền HTTPS được cấp, đổi thành wss://ten-mien-cua-ban.com và dán vào ô Máy chủ Relay ở tab Kênh Phát.
  4. Dán Khóa luồng từ YouTube Studio & Facebook Live Producer rồi bấm Bắt đầu phát Live.
Lệnh chạy nhanh trên VPS (Docker) 
docker build -t live-relay . && docker run -d -p 8080:8080 live-relay
